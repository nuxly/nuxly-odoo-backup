# nuxly-odoo-backup

## Overview

This repository contains a lightweight and customized version of the `auto_database_backup` module, originally developed by **[CybroAddons](https://github.com/CybroOdoo/CybroAddons/tree/16.0/auto_database_backup)**.  
Due to the original repository's large size, we extracted only the module (`auto_database_backup`) and built our own extension `auto_database_backup_odoo_sh` tailored for **Odoo.sh** deployments.

> **Note**: Future maintenance and updates of this codebase will be handled by **Nuxly**.
